# 要件

## 前提
- 利用者：自分（サイトの持ち主）が内容を更新し、誰でも閲覧できる
- 端末：スマホとPCの両方で見られる（スマホ優先）
- 形態：サーバーを持たない静的サイト。ログイン・DB は使わない

## 機能要件
- F1 プロフィール：名前・一行紹介・自己紹介・SNS などのリンクを表示する
- F2 リンク一覧：Webアプリ・ブログ・ポートフォリオのカテゴリごとに見出しを付けて並べる
  - 各リンクは名前・ドメイン・時期・説明・タグ・ソースコードへのリンク（任意）を持つ
  - 並び順は新しい順。時期のないものは最後、同じなら名前順
  - 項目のないカテゴリは表示しない
  - リンクは新しいタブで開く
- F3 カテゴリへのジャンプ：カテゴリが2つ以上あるとき、上部に件数付きのリンクを出す
- F4 内容の検証：`src/content/site.ts` の書き間違い（URL が http(s) でない、日付の形、カテゴリ名、URL の重複など）があればビルドを失敗させ、理由を表示する

## 非機能要件
- ダークモードに対応（端末の設定に従う）
- 横スクロールが出ない
- 内容の更新は `src/content/site.ts` を書き換えて push するだけ

## 対象外（今は作らない）
- 記事本文の執筆・管理（ブログ本体は外部サービス）
- お問い合わせフォーム、アクセス解析
