# 要件

## 前提
- 利用者：自分（サイトの持ち主）が内容を更新し、誰でも閲覧できる
- 端末：スマホとPCの両方で見られる（スマホ優先）
- 形態：サーバーを持たない静的サイト。ログイン・DB は使わない

## 機能要件
- F1 プロフィール：名前・一行紹介・自己紹介・SNS などのリンクを表示する
- F2 リンク一覧：自分のWebアプリへのハブとして、アプリをいちばん上に大きく並べる。その下にブログ・ポートフォリオ
  - 各リンクは名前・ドメイン・説明（2行まで）・アイコン・ソースコードへのリンク（任意）を表示する
  - カード全体が1つのリンクで、どこを押しても開く。アプリのカードは高さ 96px 以上で「開く」ボタン付き
  - ソースコードへのリンクは押し間違えないよう、カードの外に分けて置く
  - アイコンは指定した絵文字、なければ名前の頭文字。背景色は名前から決まる
  - 並び順は新しい順。時期のないものは最後、同じなら名前順
  - 項目のないカテゴリは表示しない
  - リンクは新しいタブで開く
- F3 内容の検証：`src/content/site.ts` の書き間違い（URL が http(s) でない、日付の形、カテゴリ名、アイコンの文字数、URL の重複など）があればビルドを失敗させ、理由を表示する

## 非機能要件
- ダークモードに対応（端末の設定に従う）
- 横スクロールが出ない
- 自己紹介は小さくまとめ、スマホで開いてすぐアプリのボタンが見える
- 押せる部分は高さ 44px 以上。押したときに縮む反応を付ける
- SNS のリンクはページ下部
- 内容の更新は `src/content/site.ts` を書き換えて push するだけ

## 対象外（今は作らない）
- 記事本文の執筆・管理（ブログ本体は外部サービス）
- お問い合わせフォーム、アクセス解析
